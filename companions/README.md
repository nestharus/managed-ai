# Shared optional companions

These adapters use the same central [engine](../engine/README.md). They contain no second native runtime or source corpus.

- [Workbench](workbench/README.md): model/tool callbacks, explicit source acquisition, durable resumption and peer contributions.
- [Peer harness](harness/PROTOCOL.md): caller-selected participant processes and bounded exchanges.
- [Publication](workbench/PUBLICATION.md): declared source changes, receiving review and exact receipts.

Select the corpus and receiving store for the actual contribution. The trusted lexical reader is `engine/prototype/knowledge-system/knowledge.py`; corpus directories hold data. The native store’s domain/source catalogues are the primary route when source exposure or typed records must follow that store’s selection. Companion registration and source discovery do not establish participant acquisition or semantic acceptance.
