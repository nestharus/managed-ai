# Compose through representations qualified for their use

Use this companion when a task requires deliberate construction across interacting source perspectives. A capable participant supplies meaning, source fit, models, choices and receiving judgments. The native runtime retains captured inputs, returns and explicit adoption. The optional adapter in `companion/representation.py` binds an authored operation to accepted JSON representations; it does not infer semantics or follow another owner's current state automatically.

## Keep the actual commission reachable

Retain the requested outcome and any commissioned finite inventory outside a single model context. Keep identities and outstanding duties navigable without putting every operative source body into the governing record. Historical source treatment does not automatically discharge a new use. A locally completed contribution remains separate from the containing duty.

Select the next question from consequential effects and gaps in the developing artifact. Search and source hints nominate routes. Acquire the sources whose meanings matter, including their conditions. Let overlap, actual returns and necessary neighbors change the next selection. A numbered portion of an inventory is not itself a semantic job. A scoped composing owner can join a particular useful whole; it need not become a permanent central semantic integrator.

## Make a representation do productive work

Represent the relations the current consumer needs: possible states, ownership, alternatives, dependencies, information available to a participant, or another useful shape. No outline, ontology, hierarchy or domain schema is mandatory. Prose can retain relations; structured files help when exact sharing or manipulation matters.

Before a selected operation, state what difference it should make and what would challenge it. Bind the accepted representation and actual source bodies into the producing context. Return the changed representation or realization with an account of the actual source applications. A source name, JSON field, hash or finished audit row alone does not establish productive use.

Choose an adequate existing route. Ordinary native capture, source-informed construction, receiving and adoption can be sufficient. Use the optional adapter's `prepare`, `receive` and `adopt` when its explicit representation bindings serve the operation. Inspect the actual captured material in either route. Retain failed or stale returns and their earlier forecasts. The adapter verifies custody and declared bindings; it cannot judge whether an authored account is true.

## Let a partial whole expose the next gap

A scoped provisional realization can begin once its actual producing relations are adequate. It need not wait for every surrounding question to close. Keep the remaining commission active. Select the model relations the current fragment consumes instead of flattening every prior model and source into one large instruction sheet.

Give the actual partial to the owner whose predicate can distinguish a useful difference. Return a discrepancy to the representation or operation that produces it, then realize the changed relation. Do not silently tidy the surface and attach a retrospective model. Some observations support retaining a candidate; not every source needs a visible edit.

## Make the currency promise explicit at the effect

Name what the receiving use promises. A fixed published edition, an unchanged manuscript identity and the latest responsible assessment are different source relations. A changed assessment can require a new current decision while leaving a historical account and an independent recovery instruction adequate.

For a current use, identify the responsible origin, the interpretation or relationship being consumed, and the owner that can admit the effect. A locally accepted copied representation identifies an acquired occurrence. It does not establish that a separate origin is still current. Its own hash can remain unchanged while later findings make its measurements or next action obsolete.

Acquire and receive the current origin before construction. If the source can change before the effect, enroll the relevant current source at the effect's owner. Where the existing Collective owner holds the actual authoritative source and target, `capture` selects those occurrences, `propose` retains the returned candidate, and `publish` checks the selected source and target while admitting the effect. This guard covers the enrolled owner-held artifacts. It does not discover an external source, import new meaning automatically or supply semantic acceptance.

Keep two decisions distinct: whether the actual candidate serves the intended meaning, and whether its source/target basis still holds when it is admitted. Both are necessary for the promised current use. A prior source read alone leaves an interval in which the basis can change. A mechanical guard alone cannot decide whether refreshed prose incorporates the changed meaning.

On an actual `basis-changed` refusal, retain the candidate and receipt. Acquire the new source, reopen the relevant prediction, and judge what changes in the producing relation. Return a revised candidate or an explicitly justified unchanged candidate through the new capture; do not merely substitute a new pin for obsolete prose. Repeat admission under the fresh basis. Keep independent and fixed-history consumers on their own declared relations instead of introducing a global change barrier.

Current-at-admission is a bounded promise. After the admitted action is performed, its receipt becomes evidence of that occurrence. A continuously maintained status display has a further update duty; a completed decision need not be made self-referential by continually republishing its own completion as a new source change.

## Preserve source scopes and distinct ownership

An operation can apply directly, support a justified retained candidate, require an explicit adaptation, or lack its triggering structure. State which occurred. Do not manufacture a figure, empirical claim or other structure merely to increase a source's applicability. Do not turn a conditional detector into a universal lexical ban.

Two sources can govern different owners or uses of the same bytes. An instruction for new authoring may conflict with preserving a received quotation or fixed external contract. Resolve that relationship in the model and carry the result into production. A shared observation may qualify multiple predicates, but the source-specific consequences and limitations remain separate.

## Measure the complete selected exposure

Raw source counts describe only those sources. For delivery questions, count all captured input bodies and the rendered context, including governing records, methods, accepted models, source/target bases, operation specifications and receiving evidence. Include failed construction, reacquisition and reentry in the route being described. Report other observed reads separately; a native packet census is not the whole conversation or provider-token bill.

Exact repetition is an observation, not proof that the repeated material was unnecessary. Different owners can need the same source, and one body can carry distinct source and target-guard roles. Avoid explicitly selecting a guide that the native method already supplies when no distinct source role requires it. Reduce repeated text only while preserving the needed meaning, owner and guard. Compare adequate routes on the same task, source edition, receiving promise and useful output before making a savings or superiority claim.

## Receive actual outcomes before retrying

Inspect the command's actual returned envelope and retained owner state. The representation adapter's `receive` returns the retained native return object directly; the native `system.py` CLI's `receive` wraps that object with `return` and `status`. Do not assume these envelopes are interchangeable. A caller exception while formatting a successful response does not establish that the effect failed. Recover the existing result before deciding whether another attempt is necessary. Keep the original attempt and its timing visible.

## Close the duty with actual receiving

Join the inventory identities to the current source/use accounts and inspect original witnesses where needed. A mechanical join can find missing identities, stale hashes or missing records; it cannot certify meaning. Require the actual receiving judgments and effect receipts that the claimed outcome depends on, including the complete current artifact and substantive overlaps.

Keep unavailable or unperformed tests distinct from the narrower operation actually used. A textual cadence analysis is not an audible reading, a model reader is not a human population, and a constructed component is not measured comparative advantage. Complete the selected duty when its evidence supports it. Reopen the broader hypothesis with the remaining uncertainty stated; do not generate additional near-identical fixtures merely to extend a test count.
