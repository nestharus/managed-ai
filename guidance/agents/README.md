# Agent operating guidance

This is the current agent entrance. Use the [operating principles](AGENTS.md), [guide](guide.md) and [constructive methods](methods.md) for actual work. [Shared systems](shared-systems.md) connects records, source use, receiving and responsibility; [software patterns](software-patterns.md) supplies more specific design boundaries. [Worked discovery](worked-discovery.md) and [worked examples](worked-examples.md) preserve substantive demonstrations with their qualifications.

For applying these methods to an external or existing system, acquire [current application guidance](../../domains/research/sources/knowledge/research/current/application.md) as `research/current/application.md`. It connects [review of an unfamiliar artifact](worked-examples.md#review-an-unfamiliar-artifact) with [direct and joined owner work](../../domains/research/sources/knowledge/research/patterns/system-map.md#directing-work-across-independent-owners). This is a task-specific entrance; a lexical result listing does not establish source applicability.

The package has one shared engine, reusable domains and independent research, novel and discovery stores. From the package root, inspect an initialized instance with:

```bash
python -B engine/prototype/deploy.py --deployment deployments/research system status
python -B engine/prototype/deploy.py --deployment deployments/research system show C1
python -B engine/prototype/deploy.py --deployment deployments/novel system status
python -B engine/prototype/deploy.py --deployment deployments/discovery system status
```

The [research store](../../stores/research/README.md) owns the general field and received findings. The [novel store](../../stores/novel/README.md) owns its artifact, current source account and three commission duties. The [discovery store](../../stores/discovery/README.md) owns developing signals, inquiry artifacts and the actual construction of its discovery arrangement; the original research and novel duties stay with their owners. The [AI-system-building domain](../../domains/ai-system-building/README.md) supplies system development. Select complete catalogue bodies according to the task. Availability, delivery, acquisition, interpretation and useful effect remain different claims.

Respect each record's source and effect owner. Cross-instance receipt preserves a source pin and receiver account; it does not silently adopt or overwrite a remote current head. Retain only material with a current operational, evidential, corrective or owed use. New schema or domain registration supplies no semantic understanding by itself.
