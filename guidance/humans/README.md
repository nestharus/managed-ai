# Human guide to developing useful AI work

The system helps a capable person or model develop useful work, retain what later work needs, and carry a contribution into its actual receiving use. An observation can change the artifact, the question, the means or the division of responsibility. A sufficient direct answer can finish a duty.

## Choose the explanation serving your question

| Question | Complete guide |
| --- | --- |
| What is the proposal? | [Short introduction](short-story.md), then [worked discovery](worked-discovery.md) |

These are first-class current explanations. They need no runtime installation to be read. Their detailed examples preserve distinctions between conditional arguments, actual observations and unmeasured broader claims. Old example locators and historical future-tense language do not select a current engine or create another assignment.

The delivered project contains one shared engine, reusable research/writing/AI-system-building domains, and initialized research, novel and discovery instances. The research instance owns current questions and research reconciliation. The novel instance owns the current manuscript and writing commission. The discovery instance develops signals and inquiry methods and tests its own construction through actual receiving uses. See the [research](../../stores/research/README.md), [novel](../../stores/novel/README.md) and [discovery](../../stores/discovery/README.md) entrances for their current work. The discovery instance adds no duplicate owner of the original five duties.
