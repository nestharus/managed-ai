# Scope a receiving observation

The operator owns the denominator in `registry.json`. The example uses two fictional dispatch obligations. Supply your own registry and routes with the `--registry` and `--routes` options. The registry names each complete owner, digest, line range, interpretation, target unit and distinction to observe. Group obligations around concrete decisions in `routes.json`. A second route can select the same obligation without duplicating its status. Keep both files with the custodian.

From this directory use `python scope.py --ledger /tmp/new-ledger.json init /path/to/product`, followed by `python scope.py --ledger /tmp/new-ledger.json issue /path/to/product dispatch --limit 1`. This issues a bounded view to the assessor. Keep the view outside the writer’s and unaided receiver’s packets. For `receive PRODUCT TICKET OBSERVATION.json`, identify the issued obligation, registered unit and contrast, actual sample target, observed decision, exact product quote and character offset, owner quote, reviewer, result and reason. An inapplicability finding also requires an explicit applicability reason. See `test_coverage.py` one directory up for a complete example.

An assessor must determine that the sampled object actually exercises the registered distinction. A correct tag check does not establish a delivery destination. A matching string is insufficient, and this operator ledger cannot adjudicate meaning or authenticate a claimed role. Assign an independent review when a shared observation is used for more than one obligation. Establish human and phase authority separately.

`release PRODUCT TICKET` reopens unobserved obligations. `status PRODUCT` reports the complete denominator. After a product change, run `reconcile PRODUCT`. If the owner, interpretation, target unit, contrast or routing changes, edit the registry or routes and call `supersede PRODUCT PREVIOUS_BASIS REASON`. Both paths preserve superseded judgments and invalidate outstanding tickets. Every current status reopens, including earlier passes, until someone checks the new basis. The CLI uses POSIX file locking and operates on operator-controlled local files.
