Appoint a separate final reviewer at `init` using `reviewer`, or explicitly reuse the original receiver for a repeat. Identify who can authorize each phase. If the owner requires a human, wait for that person before the dependent action or declare an adapted study prospectively. Identify the effect the receiver could observe and what would distinguish an alternative. Abstain when authority, opportunity or a meaningful distinction is missing.

Record any limits on isolation. Group overlapping obligations around the same concrete decision only when each can change it. One group can span several decisions. Revisit earlier choices when a source, partial or response changes.

## Interrupted packet issuance

The single custodian runs this host on a local POSIX filesystem with atomic rename and directory sync. Keep `prepared/`, `objects/` and `events.jsonl` private. Hand off only the completed `outbox/<event>/` after `issue` or `issue-review` succeeds. A frozen private packet precedes journal commitment. The public directory appears in one rename after commitment. Publication alone cannot establish who saw a packet.

After interruption, rerun the same issuance with its original prior event, actor, purpose and question bytes. While that issuance is the current journal event the host can finish publishing its private packet or return the same event for the existing verified packet. A complete prepared packet rejects a changed question. A partial private build can be reconstructed. A later encounter stage rejects replay of an earlier issuance. Send the packet only if the custodian can independently establish that it still requires handoff. An actual return or review is a separate event.

If the host reports uncertain delivery, preserve both the journal and packet directories and compare the last event with the independently retained pin and any receiver-side receipt. A legacy public packet with no committed issuance, missing copies, divergent copies, and altered bytes require custodian investigation. Do not count that exposure as a fresh unaided encounter. Use a newly identified encounter if a new opportunity is required. New event writes replace the journal atomically. A legacy incomplete last line is held for recovery against the independent pin. The host cannot reconstruct a previously unrecorded receipt.
