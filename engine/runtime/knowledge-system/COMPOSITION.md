The information model separates a logical source identity, complete content hash, interpretation-bearing module entry, exact catalogue edition and actual current adoption. A changed whole can require different participation even when every member object's hash stays the same. Conversely, a source edit need not invalidate every use. The capable receiver retains the meaning of that relationship, with a source-pinned collective offer available when another owner needs to reconsider it.

The existing pattern-library adapter remains useful for a known small pattern body and Exchange preparation. This component adds a complete broader corpus, overlapping module products and data interchange. It does not duplicate the agent-system's goals, versioned runtime records or owner adoption machinery. A host can compose those mechanisms when the receiving contribution needs them, or use ordinary complete files and a direct adequate interpretation.

The tests select consequential boundaries: exact required closure and optional parents, stale pins, explicit collisions, malformed packages before mutation, bounded full-body selection, deliberate source relocation and discovery of newly added current source IDs. They establish the mechanical relationships exercised. The actual peer receiving encounter tests a different relationship: whether the selected product and supplied capable host support the stated work and reveal a meaningful change elsewhere. Do not relabel test fixtures as independently interpreting agents.

Further development should follow actual receiving gaps. A semantic retrieval service might improve a hard discovery use; an external source connector might supply a missing corpus; a larger corpus might need a different storage/scan arrangement. None follows solely from reaching this file. Keep the complete acquired direct route as a competitor and change the producer or representation whose relationship actually failed.

## Select the semantic unit before acquiring it

Complete-body acquisition protects the unit the caller actually selected. A compact qualified view can be that unit under its own identity, purpose and validity conditions. The adapter must not substitute a navigation summary for the requested source; neither does it require all ancestors of a sufficient view in one context. A capable participant can refine a view, obtain a local answer or construct a missing joining observation. The source `research/patterns/scoped-understanding.md` connects this choice to semantic junctions and intended coverage. The current code already supplies the required exact acquisition and discovery; no semantic classifier was added.

## Probe composition and its receiving use separately

An overlapping-library product can be checked against the direct selection from one adequate library. Exact body entries, complete bytes, required modules, optional parent roles and external participation must retain their declared meanings. A prior/current same-identity comparison can remain available while an ambiguous operative export is refused. The current implementation compares full metadata entries, so equal body hashes alone do not authorize merging differing source or reference meanings.

Those checks do not assess every later use. Let a capable recipient construct the requested contribution from the imported product, then inspect any additional source it needs when the receiving question changes.
